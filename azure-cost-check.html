How the Azure Cost Check Works

The analyzer uses deterministic rules and heuristics to scan line items in your export for common cloud cost pitfalls:

💾 Unattached Disks & Old Snapshots

When virtual machines are deleted without their attached managed disks, Azure continues billing disk storage fees indefinitely until explicitly removed.

🌐 Unused Public IP Addresses

Static and dynamic public IPs that are not associated with a running network interface card or load balancer accrue hourly idle reservation charges.

💤 Non-Production Compute Sprawl

Development, staging, and QA environments that run 24/7 over weekends and holidays often account for up to 65% unnecessary compute spend.

📈 Cost Anomalies & Spikes

Identifies sudden day-over-day cost surges on specific meters or data transfer egress that deviate significantly from historical baselines.

Analysis Methodology & Technical Limitations

Billing data indicates what was charged, but cannot reveal internal workload metrics. For instance, determining whether a Virtual Machine is oversized requires real-time CPU, RAM, and disk IOPS telemetry from Azure Monitor, which cannot be determined from billing CSV files alone. We clearly flag such findings as Requires Azure Telemetry to maintain strict technical honesty.
